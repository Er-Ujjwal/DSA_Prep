# [Delete All Occurrences in DLL](https://www.geeksforgeeks.org/problems/delete-all-occurrences-of-a-given-key-in-a-doubly-linked-list/1)
## Medium
Given the head of a doubly Linked List and a key x . Delete all occurrences of the given key x if it is present and return the new DLL.
Examples:
Input: 2&lt;-&gt;2&lt;-&gt;10&lt;-&gt;8&lt;-&gt;4&lt;-&gt;2&lt;-&gt;5&lt;-&gt;2, x = 2Output:  10&lt;-&gt;8&lt;-&gt;4&lt;-&gt;5
Explanation: 
All Occurrences of 2 have been deleted.
Input: head = 9&lt;-&gt;1&lt;-&gt;3&lt;-&gt;4&lt;-&gt;5&lt;-&gt;1&lt;-&gt;8&lt;-&gt;4, x = 9Output: 1&lt;-&gt;3&lt;-&gt;4&lt;-&gt;5&lt;-&gt;1&lt;-&gt;8&lt;-&gt;4
Explanation: 
All Occurrences of 9 have been deleted.
